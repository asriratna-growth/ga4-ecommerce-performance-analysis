# Metrics

This folder documents the key metrics and performance indicators used in the GA4 Ecommerce Performance Dashboard.

## Core Metrics

| Metric                  | Description                                        |
|-------------------------|----------------------------------------------------|
| Users                   | Unique users who visited the ecommerce website     |
| Sessions                | Total browsing sessions                            |
| Purchases               | Total completed purchase transactions              |
| Purchase Revenue        | Total revenue generated from completed purchases   |
| Conversion Rate         | Percentage of sessions that resulted in a purchase |
| Revenue per Session     | Average revenue generated per session              |

## Acquisition Metrics

| Metric                  | Description                                        |
|-------------------------|----------------------------------------------------|
| Acquired Users          | Users acquired through each marketing channel      |
| Channel Sessions        | Sessions generated by each traffic channel         |
| Purchasing Users        | Users who completed a purchase                     |
| Channel Revenue         | Revenue generated by each acquisition channel      |

## Funnel Metrics

| Metric                  | Description                                        |
|-------------------------|----------------------------------------------------|
| View Item Users         | Users who viewed a product                         |
| Add to Cart Users       | Users who added a product to their cart            |
| Begin Checkout Users    | Users who started the checkout process             |
| Add Shipping Info Users | Users who entered shipping information             |
| Add Payment Info Users  | Users who entered payment information              |
| Purchase Users          | Users who completed a purchase                     |

## Checkout Metrics

| Metric                  | Description                                        |
|-------------------------|----------------------------------------------------|
| Checkout Users          | Users who entered the checkout process             |
| Shipping Users          | Users who progressed to the shipping stage         |
| Payment Users           | Users who progressed to the payment stage          |
| Purchase Users          | Users who completed the purchase                   |

## Landing Page Metrics

| Metric                  | Description                                        |
|-------------------------|----------------------------------------------------|
| Landing Page            | First page visited during a session                |
| Sessions                | Sessions starting from each landing page           |
| Users                   | Unique users associated with each landing page     |
| Purchases               | Purchases generated by users landing on the page   |
| Revenue                 | Purchase revenue associated with the landing page  |
| Conversion Rate         | Percentage of sessions resulting in a purchase     |

## Performance Trend Metrics

| Metric                  | Description                                        |
|-------------------------|----------------------------------------------------|
| Daily Users             | Unique users by date                               |
| Daily Sessions          | Sessions by date                                   |
| Daily Purchases         | Purchases by date                                  |
| Daily Revenue           | Purchase revenue by date                           |
| Conversion Rate         | Daily purchase conversion rate                     |
| Revenue per Session     | Average revenue generated per session              |

> Note: Metric definitions are based on the reporting tables and SQL logic used in this project.

# Documentation

This folder contains supporting documentation for the GA4 Ecommerce Performance Analysis project.

The documentation explains the project objective, dataset, methodology, metrics, and dashboard structure.

## Documentation Files

### Project Overview

`project_overview.md`

Provides an overview of the project, including:

- Business objective
- Dataset information
- Analysis scope
- Key business questions

### Data Dictionary

`data_dictionary.md`

Documents the key fields, dimensions, and metrics used throughout the analysis.

### Methodology

`methodology.md`

Explains the end-to-end analytical workflow, from data preparation to reporting tables, analysis queries, and dashboard development.

### Dashboard Guide

`dashboard_guide.md`

Provides guidance for understanding the dashboard pages, metrics, and key visualizations.

## Project Workflow

`GA4 Dataset → Data Preparation → Reporting Tables → Analysis Queries → Dashboard → Business Insights`

For technical implementation details, refer to the `sql/` and `dashboard/` folders.

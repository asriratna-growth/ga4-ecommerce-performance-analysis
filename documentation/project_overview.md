# Project Overview

## Project Objective

The GA4 Ecommerce Performance Analysis project evaluates the end-to-end ecommerce performance of the Google Merchandise Store using Google Analytics 4 (GA4) data.

The analysis aims to identify opportunities to improve customer acquisition, conversion performance, checkout efficiency, and revenue generation through data-driven insights.

## Business Questions

The analysis addresses the following key business questions:

1. How is the overall ecommerce business performing?
2. Which acquisition channels generate the highest-quality traffic and revenue?
3. Where do customers drop off during the purchase journey?
4. How effective is the checkout process across different devices?
5. Which landing pages contribute most to revenue and conversions?
6. What strategic actions can improve overall ecommerce performance?

## Dataset

| Attribute | Description |
|---|---|
| Dataset | GA4 Obfuscated Sample Ecommerce Dataset |
| Source | Google BigQuery Public Dataset |
| Platform | Google Analytics 4 (GA4) |
| Industry | Ecommerce Retail |
| Analysis Period | November 1, 2020 – January 31, 2021 |
| Duration | 92 days |
| Granularity | Event-level data |
| Currency | USD |

## Analysis Scope

The analysis covers:

- Overall ecommerce performance
- User acquisition and traffic channels
- Ecommerce conversion funnel
- Checkout performance
- Landing page effectiveness
- Conversion and performance trends
- Business insights and strategic recommendations

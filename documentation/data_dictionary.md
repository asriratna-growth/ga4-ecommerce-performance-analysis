# Data Dictionary

This document defines the key dimensions, fields, and metrics used throughout the GA4 Ecommerce Performance Analysis project.

## Core Metrics

| Metric | Description |
|---|---|
| Users | Unique users who visited the ecommerce website |
| Sessions | Total browsing sessions |
| Purchases | Total completed purchase transactions |
| Purchase Revenue | Total revenue generated from completed purchases |
| Conversion Rate | Percentage of sessions that resulted in a purchase |
| Revenue per Session | Average revenue generated per session |

## Acquisition Metrics

| Metric | Description |
|---|---|
| Acquired Users | Number of unique users acquired through each first-user source, medium, and campaign |
| Sessions | Total number of sessions generated by acquired users |
| Engaged Sessions | Number of sessions classified as engaged |
| Total Events | Total number of GA4 events generated by acquired users |
| Purchasing Users | Number of acquired users who completed at least one purchase |
| Engagement Rate | Percentage of sessions classified as engaged |
| User Conversion Rate | Percentage of acquired users who completed a purchase |
| Purchase Revenue | Total revenue generated from completed purchases |
| Revenue per Acquired User | Average purchase revenue generated per acquired user |
| Events per User | Average number of GA4 events generated per acquired user |

## Funnel Metrics

| Metric | Description |
|---|---|
| Total Users | Total unique users included in the funnel analysis |
| View Item Users | Users who triggered a view_item event |
| Add to Cart Users | Users who triggered an add_to_cart event |
| Begin Checkout Users | Users who triggered a begin_checkout event |
| Add Shipping Users | Users who triggered an add_shipping_info event |
| Add Payment Users | Users who triggered an add_payment_info event |
| Purchase Users | Users who triggered a purchase event |
| Funnel Conversion Rate | Percentage of View Item Users who completed a purchase |
| Stage Conversion Rate | Percentage of View Item Users reaching each funnel stage |
| Stage Drop-off Rate | Percentage of users lost between two consecutive funnel stages |
| Largest Drop-off | Funnel stage transition with the highest drop-off rate |

## Traffic Dimensions

| Field | Description |
|---|---|
| Session Source | Traffic source associated with the session |
| Session Medium | Traffic medium associated with the session |
| Session Campaign | Campaign associated with the session |
| Channel Group | Grouped classification of acquisition traffic used for channel-level analysis |

## Ecommerce Fields

| Field | Description |
|---|---|
| Total Item Quantity | Number of ecommerce items associated with an event |
| Purchase Revenue | Revenue generated from completed purchase events |
| Purchase Event | GA4 event representing a completed ecommerce transaction |
| Transaction ID | Identifier associated with an ecommerce transaction |
| Items | Product/item-level ecommerce data |

## Device Dimension

| Field | Description |
|---|---|
| Device Type | Type of device used during the customer journey, such as desktop, mobile, or tablet |

## Landing Page Dimensions

| Field | Description |
|---|---|
| Landing Page URL | Full URL of the first page viewed in a session |
| Landing Page Path | URL path extracted from the first page viewed in a session |

## Landing Page Metrics

| Field | Description |
|---|---|
| Sessions | Number of sessions beginning on the landing page |
| Users | Number of unique users associated with the landing page sessions |
| Viewed Product Sessions | Sessions in which a product view occurred |
| Add to Cart Sessions | Sessions in which a product was added to cart |
| Checkout Sessions | Sessions in which checkout was initiated |
| Purchasing Sessions | Sessions in which a purchase was completed |
| Purchase Revenue | Revenue generated from purchases associated with the landing page |
| Conversion Rate | Percentage of landing page sessions that resulted in a purchase |
| Revenue per Session | Average purchase revenue generated per landing page session |
| Purchases per 100 Sessions | Number of purchasing sessions per 100 landing page sessions |

## Time Dimensions

| Field | Description |
|---|---|
| Event Date | Date on which the GA4 event occurred |
| Date Range | November 1, 2020 – January 31, 2021 |

# Data Dictionary

This document defines the key dimensions, fields, and metrics used throughout the GA4 Ecommerce Performance Analysis project.

## Core Metrics

| Metric | Description |
|---|---|
| Users | Unique users who visited the ecommerce website |
| Sessions | Total browsing sessions |
| Purchases | Total completed purchase transactions |
| Purchase Revenue | Total revenue generated from completed purchases |
| Conversion Rate | Percentage of sessions that resulted in a purchase |
| Revenue per Session | Average revenue generated per session |

## Acquisition Metrics

| Metric | Description |
|---|---|
| Acquired Users | Users acquired through each marketing channel |
| Channel Sessions | Sessions generated by each traffic channel |
| Purchasing Users | Users who completed a purchase |
| Channel Revenue | Revenue generated by each acquisition channel |

## Funnel Metrics

| Metric | Description |
|---|---|
| View Item Users | Users who viewed a product |
| Add to Cart Users | Users who added a product to their cart |
| Checkout Users | Users who entered the checkout process |
| Shipping Users | Users who reached the shipping information stage |
| Payment Users | Users who reached the payment information stage |
| Purchase Users | Users who completed a purchase |

## Traffic Dimensions

| Field | Description |
|---|---|
| Source | Traffic source that generated the session |
| Medium | Medium associated with the traffic source |
| Campaign | Campaign associated with the traffic |
| Channel Grouping | Grouped classification of acquisition traffic |

## Ecommerce Fields

| Field | Description |
|---|---|
| Total Item Quantity | Number of ecommerce items associated with an event |
| Purchase Revenue | Revenue associated with a completed purchase |
| Transaction ID | Identifier associated with an ecommerce transaction |
| Items | Product/item-level ecommerce data |

## Device Dimension

| Field | Description |
|---|---|
| Device Category | Device type used during the customer journey |

## Landing Page Dimensions

| Field | Description |
|---|---|
| Landing Page | First page visited during a session |
| Sessions | Number of sessions beginning on the landing page |
| Purchases | Purchases generated from sessions associated with the landing page |
| Revenue | Revenue generated from those sessions |

## Time Dimensions

| Field | Description |
|---|---|
| Event Date | Date on which the GA4 event occurred |
| Date Range | November 1, 2020 – January 31, 2021 |
